Selected work

LedgerDesk

Document operations platform, 2026. Design and front end.

Accounting teams were reviewing client documents through email and spreadsheets. I designed the review surface: one queue, one set of states, no ambiguity about what is done and what is not.

Problem

Six document states existed in the data and none of them existed on screen. Reviewers were guessing.

Decision

Numbers carry the meaning. Pending, punched, invalid each get a value and a colour from one token table. Navigation, tables and dialogs all read from the same tokens.

Result

Light and dark share one layout. Contrast checked at 4.5:1 for body text. The 16 hour review cycle is now a queue with a visible end.

Tripp'in AI

Consumer travel app and route planner, 2026. Design system, Android UI, web UI.

A travel planner that produces a fixed itinerary instead of a chat answer. The hard part was making a dense plan readable on a phone, so I gave it the visual language of a flight briefing: numbered steps, form headers, one accent, physical depth instead of shadows.

Problem

One font size did eight jobs. Colour was decoration. Every card shouted at the same volume, so nothing read as important.

Decision

I wrote the design system before touching screens: colour carries meaning and nothing else, a type scale with real steps, one accent for anything tappable.

Result

The system is enforced, not admired. Every token has a rule, a value and a contrast check, and the Android and web surfaces use the same table.

God's Eye View

Satellite imagery analysis console, 2026. Interface design.

An analyst tool that pulls imagery for a place and a date range. Dense by necessity: coordinates, sensor metadata, capture history and the image itself all have to be visible at once without crowding each other.

Problem

Analysts cross reference numbers while looking at an image. A layout that hides either one costs them the task.

Decision

Fixed panels, no floating windows. Numeric values in monospace so they line up when scanned. One accent reserved for the active selection.

Result

A console that stays quiet while the data is loud. Readable at a glance, still readable at 2am.

How I work

Rules I design by

These are not preferences I picked up, they are rules I can defend in a review. Each one came out of a screen that failed.

RuleWhy
One accent, and it means tappableIf colour is decoration it stops being information. The accent is the only saturated thing on the screen.
Colour carries meaningA badge is red because something is wrong, not because the row looked empty.
Typography does the hierarchyTwo font sizes doing eight jobs reads as a wall. A real scale tells you what to read first.
Light and dark are both designedDark mode is not an inverted stylesheet. Surfaces, borders and emphasis change with it.
43 pixels is not a tap targetControls get 44px minimum and 16px text on mobile so iOS never zooms the input.
Revise, do not stackPatches on top of patches produce screens nobody can reason about. If it is wrong structurally, rebuild it.
